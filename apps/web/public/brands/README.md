- ENS usage guidance: https://github.com/ensdomains/thorin/blob/main/docs/src/guides/logo.mdx

Assets retain original colors and proportions. Marks identify technology used by this independent prototype; they do not imply endorsement. The app uses shadcn components with ENS-inspired tokens, not the Thorin component runtime. Text/action blue is darkened for contrast against white.
